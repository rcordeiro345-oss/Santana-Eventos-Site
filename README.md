# Santana Eventos

Site responsivo do Santana Eventos para locação de espaço para festas e eventos. O espaço tem capacidade para até 150 pessoas e fica na Rua Ulisses do Prado Nogueira, 927 A, Bairro Morada dos Pássaros – Felícia. Atendimento das 09h às 18h.

## Desenvolvimento

Requer Node.js e npm.

```sh
npm ci
npm run dev
```

## Verificação de produção

```sh
npm run build
npm run preview
```

As fotos finais do espaço ainda serão adicionadas. Os pontos de entrada dos carrosséis ficam no array `imagensEspaco` em `src/App.tsx`.
